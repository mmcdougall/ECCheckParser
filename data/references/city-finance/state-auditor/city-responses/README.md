The May 2021 cover letter is undated. The State Auditor's source index identifies
submission on May 14, 2021; the local filename therefore uses the verified
month rather than assigning that date to the document itself. For September
2023 and March 2024, filenames use the cover-letter date, September 16 and
March 16 respectively, rather than the submission dates shown in some indexes.

The [collection manifest](../../manifest.json) records URLs, byte counts,
SHA-256 checksums, page counts, and text-extraction scope. The first six files
come from the State Auditor's published attachments; the March 2024 file comes
from the City's State Auditor report page. No attachments have been removed.
