# Civic purpose and project values

## Why this project exists

ECCheckParser is an independent civic project for understanding the City of El
Cerrito's published financial records. Those records are public, but important
information is often embedded in large agenda-packet PDFs. The project reduces
that mechanical barrier so residents, public servants, journalists,
researchers, and technologists can inspect the same source material more
easily.

This is a coarse tool working from coarse public records. Automated PDF
extraction is imperfect. Its results are evidence to inspect, not an audit,
official accounting, or substitute for the original City documents.

## Values

### Understanding before accusation

Civic transparency should help people understand how a city works. Scrutiny,
criticism, and disagreement are legitimate; stripping away context or using
automation to make weak claims look authoritative is not the purpose of this
project.

### Source before claim

Analysis should remain traceable to the records from which it came. Users
should retain source references, disclose extraction limitations, and verify
important claims against the original documents.

### Auditability over control

The project does not try to control viewpoints or lawful criticism. It instead
favors reproducible methods, visible limitations, reconciled totals, preserved
source material, and enough metadata for another person to check the work.

### Credit that travels

Software is part of its creators' durable record. Copies and derived projects
should preserve the statement that Michael McDougall created and originally
architected this project. Later maintainers and contributors deserve durable
credit for their work as well.

### Improvements returned to the commons

Commercial and noncommercial use are welcome. The project uses the GNU Affero
General Public License so distributed improvements remain free software and
users of modified network services can obtain the corresponding source.

## A request to users

Please:

- credit the creator and later contributors;
- do not present a modified version as maintained or endorsed by Michael
  McDougall, the City of El Cerrito, or its Financial Advisory Board;
- identify the source documents and limitations behind generated results;
- verify material conclusions against the City's original records;
- share corrections and improvements; and
- comply with the source-sharing requirements in [`LICENSE`](../LICENSE).

This statement describes the project's purpose and community norms. It does
not add a restriction on permitted fields of use or replace the license.

## Independent status

This is an independent project created by Michael McDougall as an El Cerrito
resident. It is not assigned, sponsored, maintained, or endorsed by the City
of El Cerrito or its Financial Advisory Board.

## Working name

`ECCheckParser` is the project's original working name. A future release may
adopt a clearer name that reflects its civic-finance and public-records
mission. A rename does not change the project's authorship or history.
